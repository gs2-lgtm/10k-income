# 30 天行动计划：目标 $10,000

## 0. 一句话版本

挑一个行业（例如美国的屋顶维修 / 空调维修 / 清洁公司），每天找一批“网站很差或没有网站”的商家，由我为每家**提前做好一个新网站样品**，你把样品链接发给老板，约 15 分钟视频或电话，成交后收款，我负责交付。

## 1. 收入目标拆解

**产品套餐（英文报价，卖给海外商家）**

| 套餐 | 内容 | 价格 |
|---|---|---|
| Starter | 新网站（5 页以内）+ 上线 + 谷歌商家资料优化 | **$997** 一次性 |
| Growth（主推） | Starter + 网站 AI 客服 + 未接来电自动回短信 + 在线预约 | **$1,997** 一次性 + **$197/月** |
| 维护（任意套餐可加） | 托管、修改、每月报告 | **$97–$197/月** |

**要达到 $10,000，大约需要：**
- 4 个 Growth + 2 个 Starter ≈ $10,000；或者
- 8–10 个 Starter + 若干维护费。

**倒推工作量（按保守转化率估算）：**

| 环节 | 转化率 | 需要数量 |
|---|---|---|
| 成交客户 | — | **7 个** |
| 通话 / 视频会议 | 25% 成交 | 28 次 |
| 正面回复 | 40% 愿意通话 | 70 个 |
| 发出推销（附样品） | 5% 正面回复 | **约 1,400 个商家** |

→ 平均每个工作日要联系约 **60–70 家**。邮件、短信、电话、社交私信几种方式叠加使用。

## 2. 分工

| 我（Claude）负责 | 你负责（这些必须真人完成） |
|---|---|
| 挑选行业和城市、整理潜在客户名单 | 注册账号：域名、企业邮箱、收款、Upwork |
| 为每个潜在客户生成定制网站样品并上线 | 每天发推销消息、回复客户 |
| 写全部英文推销邮件、跟进话术、报价单、合同 | 接电话 / 视频会议（我提供逐句话术） |
| 交付：正式网站、AI 客服、自动化设置 | 发付款链接、确认到账 |
| 每天更新进度表，分析哪个环节卡住 | 每天花 **3–5 小时**，最好在美国白天时间段在线 |

> 如果你的英语口语不方便通话，可以全程用文字 + 录屏视频（我写稿，你录屏或用 AI 配音）代替，但成交率会低一些。

## 3. 每周计划

### 第 1 周（第 1–7 天）：搭好基础，开始发第一批

| 天 | 你做 | 我做 |
|---|---|---|
| 1 | 回答本文第 5 节的问题；买 2–3 个域名（每个约 $10） | 确定行业 + 城市；做公司品牌页（我们自己的官网） |
| 2 | 开通企业邮箱（Google Workspace 约 $7/个/月，每个域名开 2 个）；开始邮箱预热 | 配置邮件发信验证（SPF/DKIM/DMARC），写好第一版推销话术 |
| 3 | 开通收款（PayPal 企业版 / Payoneer / Stripe 任选能用的）；注册 Upwork 并填写资料 | 整理第一批 200 家潜在客户名单；做好 20 个网站样品 |
| 4–5 | **用你的个人邮箱/手机每天手动发 30–40 条**（不走群发，所以不需要预热） | 每天新做 40 个样品；在 Upwork 每天挑 5 个合适的单子写投标 |
| 6–7 | 回复客户、约通话 | 根据回复率修改话术；准备通话话术和报价单 |

**本周目标**：发出 150+ 推销，拿到 5+ 正面回复，约到 1–2 次通话。

### 第 2 周（第 8–14 天）：加大发送量，拿下第一单

- 预热好的邮箱开始使用群发工具（如 Instantly，约 $37/月），每个邮箱每天 30 封以内。
- 增加渠道：给商家打电话、在 Facebook / Instagram 私信、在商家网站的联系表单留言。
- **目标**：每天联系 60+ 家，**成交第 1–2 单**（哪怕首单打折到 $500，先拿到案例和好评）。

### 第 3 周（第 15–21 天）：复制成功做法

- 只保留回复率最高的行业 + 话术，其他停掉。
- 用前几个客户做案例（“我们帮 XX 公司 3 天上线了新网站”），放进推销里。
- 对已成交客户推销加价项：AI 接电话、预约系统、谷歌评价自动邀请。
- **目标**：累计 4–5 单，收入 $5,000+。

### 第 4 周（第 22–30 天）：冲刺 + 转成每月收入

- 所有还在考虑的客户统一跟进，给一个期限内有效的优惠（例如月底前签约免首月维护费）。
- 每个客户都推维护套餐，让下个月有保底收入。
- **目标**：累计 7 单左右，收入 $10,000；并且有 $1,000+/月 的维护收入。

## 5. 开始前需要你回答的问题

这些答案会直接改变计划，请尽快告诉我：

1. **你在哪个国家/地区？** 决定能用哪种收款方式，以及要不要考虑国内客户。
2. **你的英语水平如何？** 能否和美国客户打电话？还是只能文字沟通？
3. **每天能投入几小时？能否在北京时间晚上到凌晨（美国白天）在线？**
4. **启动资金能拿出多少？** $200 以内够用，有 $500 会更快。
5. **你有没有什么现成资源？** 例如认识的老板、某个行业的经验、社交媒体粉丝、已经注册好的公司或网站（比如你邮箱的域名对应的公司）。
6. **有没有不想做的事？** 例如不想打电话、不想用真名。

## 6. 风险和底线

- **诚实预期**：按调研数据，从零开始 30 天达到 $10,000 的概率估计不到三成；更常见的结果是第一个月 $2,000–$6,000，第 2–3 个月达到每月 $10,000。计划按冲 $10,000 设计，但即使没达到，也会留下客户和每月收入。
- **合规底线**：只给企业的公开商务邮箱发信；每封都写真实地址并提供退订；对方说不要就立刻停；不使用虚假身份或冒充别的公司。
- **不要做的事**：不刷单、不买粉丝、不做“AI 代写论文”这类违规服务，不向任何人交几千块学费买“赚钱课程”。
- **每天复盘**：每天记录发了多少、多少回复、多少通话、多少成交（见 [pipeline.csv](../tracker/pipeline.csv)），我根据数据调整。
