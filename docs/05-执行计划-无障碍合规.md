# 执行计划 v2：网站无障碍合规修复（30 天目标 $10,000）

## 1. 产品和价格

| 套餐 | 内容 | 价格 |
|---|---|---|
| **Audit** | 全站扫描 + 人工抽查 + 英文审计报告（列出问题、严重程度、修复方案） | **$490**（如果后续购买修复，这笔费用全额抵扣） |
| **Fix**（主推） | 审计 + 修改网站代码，修复全部已发现的问题 + 整改完成报告，5 个工作日交付 | **$1,990**（50 页以内的小网站或店铺） |
| **Fix Pro** | 大型电商、多语言网站或复杂表单 | **$3,500 起** |
| **Monitor** | 每月重新扫描，网站更新后修复新问题，出月度报告 | **$199/月** |
| **PDF** | 政府和机构的 PDF 文件修复 | **$6–$12/页** |

**$10,000 ≈ 4 单 Fix + 1 单 Fix Pro**，或者 3 单 Fix + 若干 Audit、Monitor 和 PDF 订单。

## 2. 预算分配（共 $4,000）

| 用途 | 金额 |
|---|---|
| 谷歌搜索广告（先用 $300 测试 3 天，有效再加钱） | $2,500 |
| 域名、企业邮箱、邮件群发工具 | $150 |
| 美国海关律师 1 小时咨询（用于评估项目 2，可选） | $400 |
| 读屏软件和测试工具（大多免费）、杂费 | $150 |
| 机动资金（客户多了再加广告） | $800 |

## 3. 你每天的 4 小时怎么用

| 时间 | 做什么 |
|---|---|
| 30 分钟 | 打开和我的会话，把昨天的数据（广告点击、回复、成交）告诉我 |
| 90 分钟 | 发送我准备好的邮件（给律师、网站公司、店主） |

| 60 分钟 | 账号类操作：广告后台、Stripe、向客户要网站后台权限并转交给我 |

## 4. 30 天时间表

### 第 1 周：搭建
| 天 | 你 | 我 |
|---|---|---|
| 1 | 确认用**美国公司**作为签约主体；买域名；开企业邮箱 | 起品牌名，写官网（落地页、价格页、免费扫描入口、隐私政策、服务条款） |
| 2 | 官网上线（我给你部署步骤）；用美国公司开 Stripe，生成付款链接 | 写服务合同（含“非法律意见、不保证不被起诉”等条款）和报告模板 |
| 3 | 开通谷歌广告账户，绑定付款方式 | 写好 3 组广告和关键词，设置否定关键词，避免浪费钱 |
| 4 | 广告上线，每天 $100，先测 3 天 | 整理 300 位 ADA 被告律师和 300 家网站外包公司的公开邮箱 |
| 5–7 | 每天发 40 封合作邮件（先用个人邮箱手动发） | 扫描 100 家高风险小电商（纽约、加州等诉讼多发地区），为每家生成审计报告 |

### 第 2 周：拿下第一单
- 根据广告数据，保留有效关键词，停掉无效的，预算加到每天 $150。
- 给扫描过的店主发邮件：附上为他们生成的报告摘要，免费提供完整报告。
- **目标**：成交第 1–2 单。第一单可以给 $1,490 的首单价，换一个可以公开引用的案例。

### 第 3 周：放大
- 把前几单做成案例（修复前后对比、问题数从多少降到 0）。
- 跟进律师和网站公司的回复，签 1–2 个长期合作伙伴（给他们 15–20% 的推荐费或白标价）。
- 英国公司开始在英国和欧盟市场投放（EAA 相关关键词），并在 Contracts Finder 上投政府小标。

### 第 4 周：冲刺
- 所有付了 Audit 的客户，推销升级到 Fix（审计费抵扣）。
- 所有 Fix 客户都推 Monitor 月费，作为下个月的保底收入。
- **目标**：累计收入 $10,000，并有 $800 以上的月费收入。

## 5. 交付流程（基本都由我完成）
1. 客户付款后，你把网站后台权限交给我：Shopify 发员工账号，WordPress 开一个临时管理员。
2. 我运行 `tools/a11y-audit` 扫描全站，再人工检查键盘操作、读屏、图片说明、表单和颜色对比。
3. 我修改主题代码或模板；能先在测试环境改的，先在测试环境改。
4. 重新扫描，生成“修复前/修复后”报告。
5. 你把报告发给客户，并提醒客户收回临时权限。

## 6. 诚实的预期
- 和第一版方案相比，这个项目的客户更着急、单价更高，也不用打电话。我估计 30 天达到 $10,000 的概率大约 30%–40%。
- 最大的不确定因素是**谷歌广告的点击价格**（和法律相关的词可能每次点击 $15–$40），所以第一周只拿 $300 测试，数据不好就把重点转到律师和网站公司的合作渠道。
- 即使第一个月没达到，按月收费的客户和合作伙伴会让第 2 个月更容易做到。
